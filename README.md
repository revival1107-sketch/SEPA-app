# SEPA 종목 발굴기 (Mark Minervini 트렌드 템플릿 · VCP)

마크 미너비니의 SEPA 방법론(트렌드 템플릿 8대 기준, RS Rating, VCP)을 참고해 만든 미국/한국 주식 검색·분석 데스크톱 앱입니다.

## 바로 실행하기

`dist\미너비니종목발굴기.exe` 파일을 더블클릭하면 됩니다. 인터넷 연결이 필요합니다(야후 파이낸스에서 실시간 데이터 조회).

## 사용법

- **종목 분석 탭**: 검색창에 티커를 입력 후 분석
  - 미국/해외 종목: `AAPL`, `TSLA`, `NVDA` 등
  - 한국 종목: 6자리 종목코드만 입력 (`005930` = 삼성전자, `035720` = 카카오). 코스피(.KS)를 먼저 시도하고 없으면 코스닥(.KQ)으로 자동 재시도합니다.
  - 트렌드 템플릿 8개 조건 충족 여부, RS Rating, VCP(변동성 수축 패턴) 추정, 가격/이동평균선 차트, 매출·이익 성장률을 보여줍니다.
- **종목 발굴(스크리닝) 탭**: 미국/한국/전체 중 선택 후 "스캔 시작"
  - 미리 정의된 주요 종목 리스트(`app/universe.py`)를 대상으로 트렌드 템플릿 8개 조건을 모두 통과한 종목만 RS Rating 순으로 표시합니다.
  - 결과 행을 클릭하면 해당 종목의 상세 분석으로 이동합니다.
- **관심종목 탭**: 종목 분석 화면에서 "☆ 관심종목 추가"로 즐겨찾기하고 메모를 남길 수 있습니다. Supabase에 저장되어 PC exe·클라우드 웹·폰 어디서든 동일하게 동기화됩니다(설정 방법은 [SUPABASE_SETUP.md](SUPABASE_SETUP.md) 참고, 설정하지 않아도 다른 기능은 정상 동작).

## 유의사항

- RS Rating은 IBD 스타일 가중 상대강도 점수(3/6/9/12개월 수익률 가중 평균)를 `app/universe.py`의 유니버스 내에서 백분위로 환산한 근사치입니다. 최초 분석/스캔 시 유니버스 데이터를 한 번 내려받으므로 몇 초~수십 초 걸릴 수 있습니다.
- VCP 패턴은 스윙 고점/저점 기반 휴리스틱 추정 로직이며, 실제 차트 패턴과 다를 수 있습니다.
- 스크리닝은 전체 시장이 아닌 사전 정의된 주요 종목 리스트만 대상으로 합니다(무료 데이터 특성상 실시간 전체 시장 스캔은 느리고 불안정하기 때문). 리스트에 없는 종목도 "종목 분석" 탭에서는 티커만 알면 개별 분석이 가능합니다.
- 데이터 출처는 야후 파이낸스(yfinance)이며, 무료 비공식 데이터이므로 간헐적 오류·지연이 있을 수 있습니다. 투자 참고용으로만 활용하세요.

## 개발자용: 다시 빌드하기

```bash
venv\Scripts\pip install -r requirements.txt
venv\Scripts\python main.py          # 개발 모드로 실행(창이 바로 뜸)
venv\Scripts\pyinstaller build.spec --noconfirm   # exe 재빌드 -> dist\ 폴더
```

## 프로젝트 구조

```
main.py            # pywebview 데스크톱 진입점
server.py          # Flask API (/api/analyze, /api/screen)
app/
  data.py          # yfinance 데이터 조회, 티커 정규화(한국 6자리 코드 처리)
  analysis.py      # 트렌드 템플릿 8대 기준, RS Rating, VCP 휴리스틱
  screener.py       # 유니버스 스크리닝 및 RS 유니버스 캐시
  universe.py       # 스크리닝 대상 종목 리스트(미국/한국)
static/            # 프론트엔드(HTML/CSS/JS), Chart.js 로컬 번들
```
